# 📊 Interactive Excel Sales Dashboard


\

An interactive **Sales Dashboard built in Microsoft Excel** to analyze sales performance, profitability, product performance, regions, customer segments, and sales trends through KPIs, charts, and interactive analysis.

---

## 📌 Project Overview

This project demonstrates how Microsoft Excel can be used to transform raw sales data into an interactive business dashboard.

The workbook contains structured sales data, analytical calculations, and a visual dashboard designed to help users quickly understand overall sales performance and identify important business trends.

The project follows a simple workflow:

**Raw Data → Data Analysis → KPIs & Visualizations → Interactive Dashboard → Business Insights**

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall sales performance
* Track revenue and gross profit
* Monitor units sold
* Analyze monthly sales trends
* Compare product categories and products
* Analyze regional performance
* Understand customer segments
* Identify profitable and underperforming areas
* Present business insights through an interactive dashboard

---

## 📊 Key Performance Indicators

The dashboard analyzes important business KPIs including:

| KPI                | Description                               |
| ------------------ | ----------------------------------------- |
| 💰 Total Revenue   | Overall revenue generated                 |
| 📈 Gross Profit    | Profit generated after cost of goods sold |
| 📦 Units Sold      | Total quantity of products sold           |
| 💵 Average Revenue | Average revenue generated                 |
| 📊 Gross Margin    | Profitability percentage                  |
| 📅 Monthly Revenue | Revenue performance over time             |

The underlying dataset contains thousands of sales records and includes fields covering orders, customers, products, regions, sales channels, revenue, costs, and profitability.
